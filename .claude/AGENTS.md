# AGENTS.md

Personal memory / preferences that follow me across machines and across coding agents
(Claude Code, Cursor, Aider, etc.). This file is symlinked into each tool's expected
location by the installer:

- `~/AGENTS.md` — read by tools that follow the emerging cross-vendor convention.
- `~/.claude/CLAUDE.md` — Claude Code's global memory location.

Both point at this same source file. Add notes as they come up — coding preferences,
recurring context, things you want the agent to know every session.
